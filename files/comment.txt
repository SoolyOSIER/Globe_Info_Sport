# PROMPT — REFONTE COMPLÈTE ET PROFESSIONNALISATION DE GLOBE INFO SPORT

Je développe une plateforme web sportive appelée **Globe Info Sport**.

Le projet doit évoluer vers une **véritable plateforme d'information sportive internationale**, moderne, professionnelle, dynamique et évolutive.

Le site ne doit surtout pas être conçu uniquement comme un site consacré au sport haïtien. **Globe Info Sport doit couvrir le sport dans le monde entier**, tout en accordant une place particulière à Haïti puisque la plateforme est dirigée et alimentée par des Haïtiens.

---

# 1. ANALYSE DES SOURCES EXISTANTES

Utiliser comme références les plateformes officielles de Globe Info Sport :

* Facebook : https://www.facebook.com/Globein21
* YouTube : https://www.youtube.com/@GlobeInfosports21

Analyser en profondeur les informations, contenus, rubriques, publications, sujets traités, identité éditoriale et types de contenus présents sur la page Facebook et la chaîne YouTube.

L'objectif est de **récupérer et structurer les informations pertinentes présentes sur ces plateformes afin de les intégrer dans le nouveau site web**, lorsque leur contenu est disponible et approprié.

Ne pas simplement copier les publications.

Il faut plutôt identifier :

* les différents types d'actualités ;
* les catégories sportives ;
* les championnats suivis ;
* les clubs ;

* les reportages ;
* les événements ;
* les informations concernant Haïti ;
* les informations internationales ;

* la manière dont Globe Info Sport présente ses informations.

Transformer ensuite ces informations en une **architecture éditoriale professionnelle et cohérente pour le site web**.

# 24. IMPORTANT : NE PAS LIMITER LE PROJET À HAÏTI

C'est un point fondamental.

**Globe Info Sport n'est pas un simple site d'information sportive haïtienne.**

C'est une plateforme :

> **SPORTIVE INTERNATIONALE**

Haïti doit bénéficier d'une visibilité particulière parce que le projet est porté par des Haïtiens, mais le système doit être conçu dès maintenant pour fonctionner à l'échelle mondiale.

Un utilisateur doit pouvoir consulter aussi bien :

**Haïti → Football → Championnat haïtien**

que :

**Angleterre → Football → Premier League**

ou :

**USA → Basketball → NBA**

ou :

**France → Rugby → Top 14**

ou :

**Japon → Baseball**

ou encore n'importe quel autre sport, pays ou compétition.

# 34. RÈGLE IMPORTANTE POUR L'IMPLÉMENTATION

Avant de modifier le projet :

1. analyser l'architecture actuelle ;
2. analyser le backend ;
3. analyser le frontend ;
4. analyser les modèles existants ;
5. analyser les API existantes ;
6. analyser les pages déjà développées ;
7. analyser le système d'administration ;
8. identifier ce qui peut être conservé ;
9. identifier ce qui doit être amélioré ;
10. éviter de casser les fonctionnalités existantes.

Ensuite, implémenter progressivement les nouvelles fonctionnalités.

Ne pas créer plusieurs systèmes qui font la même chose.

Réutiliser les composants, modèles, API et services existants lorsque cela est pertinent.
